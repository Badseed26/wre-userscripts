# wre-userscripts

Tampermonkey scripts for WRE. Open an install link in a browser with Tampermonkey and hit Install. Updates come through automatically.

- Ambrose <-> AroFlo jump 3.15 (jump buttons, task name check, PO chips, invoice log, auto-reload): https://raw.githubusercontent.com/Badseed26/wre-userscripts/main/ambrose-aroflo-jump.user.js
- AroFlo photo grab 1.9 (Ambrose): https://raw.githubusercontent.com/Badseed26/wre-userscripts/main/aroflo-photo-grab.user.js
- AroFlo to Ambrose photo drag 1.4 (PC only): https://raw.githubusercontent.com/Badseed26/wre-userscripts/main/aroflo-photo-drag.user.js
- Tradies Web quick fill 1.8 (Ambrose): https://raw.githubusercontent.com/Badseed26/wre-userscripts/main/tradies-quick-fill.user.js
- WRE Calendar NPT 2.8 (PC and iPhone): https://raw.githubusercontent.com/Badseed26/wre-userscripts/main/wre-calendar-npt.user.js
  N P T (notes, photos, timesheet) badges on each booking for the days in view: green in, red missing, orange for today (including bookings that haven't started yet), blue OK'd by you. T needs two lines per person for the day: Travel and time on site (NTT, or NTA for apprentices). Click or tap a booking and the popup shows the badge with the details at the top. The lads' missing ones go on the WRE daily check list in Todoist, Ethan's own go in his WRE follow ups (due the day they're added), and both update and tick off as things come in.
- WRE Inbox Pull 1.3.1 (Outlook, PC and iPhone Safari): https://raw.githubusercontent.com/Badseed26/wre-userscripts/main/wre-inbox-pull.user.js
  Hit Pull from Outlook on the WRE Dashboard: Outlook opens, reads the day read only, sends the bundle back to the dashboard and closes. Also runs from the WRE inbox button in Outlook. On iPhone, open the dashboard in Safari (not the Claude app) and set Outlook to Request Desktop Website.
- WRE Inbox Filer 0.9.8 (PC only, beta, starts in dry run): https://raw.githubusercontent.com/Badseed26/wre-userscripts/main/wre-inbox-filer.user.js
  Watches the shared Outlook for builder POs, revised POs and Energex safety advice from the senders on the Inbox filer rules task, reads them with Claude Haiku 5.5 and files them onto the right AroFlo task: PDF attached, new works written in Lisa's layout for the boys, ESA noted. Dates to book and anything it can't do go to the To book and Errors / to check sections of WRE follow ups. Only runs in the two tabs opened from the Tampermonkey menu (Open the filer tabs), pin both and keep them open. Pause, dry run, leave dates and the sender list are on the WRE Dashboard (Inbox filer panel), with links to open the filer tabs. Builder cancellations get flagged too. Works across Ambrose, NthStar, Responsive, Reconstruct, Bentino and ARC (ARC tasks are named by the full PO like Lisa does). If a PO looks new but an open task already sits at that address without the PO number, it flags it instead of creating a double up. Stops itself after 80 Haiku reads in a day. Still to prove on real jobs: the PDF upload to AroFlo, creating a new task and location, and the header save after appending a PO.
- WRE Clipboard Brain (AutoHotkey v2, not Tampermonkey): download wre-clipboard-brain.ahk and double click it. Select text, then Ctrl+Alt+1 PO lines for the boys, Ctrl+Alt+2 customer text in your style, Ctrl+Alt+3 promise check. Preview before anything pastes.

Saved settings (API key, signature, Todoist token) live in each device's Tampermonkey, never in this repo.
