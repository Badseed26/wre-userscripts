# wre-userscripts

Tampermonkey scripts for WRE. Open an install link in a browser with Tampermonkey and hit Install. Updates come through automatically.

- Ambrose <-> AroFlo jump 3.15 (jump buttons, task name check, PO chips, invoice log, auto-reload): https://raw.githubusercontent.com/Badseed26/wre-userscripts/main/ambrose-aroflo-jump.user.js
- AroFlo photo grab 1.9 (Ambrose): https://raw.githubusercontent.com/Badseed26/wre-userscripts/main/aroflo-photo-grab.user.js
- AroFlo to Ambrose photo drag 1.4 (PC only): https://raw.githubusercontent.com/Badseed26/wre-userscripts/main/aroflo-photo-drag.user.js
- Tradies Web quick fill 1.8 (Ambrose): https://raw.githubusercontent.com/Badseed26/wre-userscripts/main/tradies-quick-fill.user.js
- WRE Calendar NPT 3.0.2 (PC and iPhone): https://raw.githubusercontent.com/Badseed26/wre-userscripts/main/wre-calendar-npt.user.js
  N P T (notes, photos, timesheet) badges on each booking for the days in view: green in, red missing, orange for today (including bookings that haven't started yet), blue OK'd by you. T needs two lines per person for the day: Travel and time on site (NTT, or NTA for apprentices). Click or tap a booking and the popup shows the badge with the details at the top. The lads' missing ones go on the WRE daily check list in Todoist, Ethan's own go in his WRE follow ups (due the day they're added), and both update and tick off as things come in.
  Ambrose jobs get a 4th letter, A: are the photos (2 or more) or the report up on Ambrose for that booking. Each visit is matched to its Ambrose booking by PO and date, with the schedule note (iso, fit off, report) as a backup; no booking that day means no A. Orange while the lads' photos aren't in AroFlo yet or it's today, red once they are and Ambrose still hasn't got them, click to OK. On the PC it checks Tradies Admin in a background tab every 2 hours (and on the header recheck), and any PO page you open there gets read too. Red ones from before today go in the Ambrose uploads section of WRE daily check, which the Desk Panel shows on its Ambrose tab. The phone shows what the PC last saw.
- WRE Inbox Pull 1.4 (Outlook, PC and iPhone Safari): https://raw.githubusercontent.com/Badseed26/wre-userscripts/main/wre-inbox-pull.user.js
  Hit Pull from Outlook on the WRE Dashboard: Outlook opens, reads the day read only, sends the bundle back to the dashboard and closes. Also runs from the WRE inbox button in Outlook. On iPhone, open the dashboard in Safari (not the Claude app) and set Outlook to Request Desktop Website. Also hands the Desk Panel's check buttons to the dashboard on the PC, so they run the same as its Run buttons (Tampermonkey asks once to allow 127.0.0.1).
- WRE Inbox Filer 0.9.48 (PC only, beta, starts in dry run): https://raw.githubusercontent.com/Badseed26/wre-userscripts/main/wre-inbox-filer.user.js
  Watches the shared Outlook for builder POs, revised POs and Energex safety advice from the senders on the Inbox filer rules task, reads them with Claude Sonnet 5.5 at high effort and files them onto the right AroFlo task: the PO plus every other PDF and photo on the email attached, new works written in Lisa's layout for the boys, ESA noted. Dates to book and anything it can't do go to the To book and Errors / to check sections of WRE follow ups. An Ambrose Schedule Update email gets its repair schedule PDF read for the electrical dates, and the job's To book item is updated or made from them. Each of those carries a link to the AroFlo task, which the dashboard shows as an Open in AroFlo button. Only runs in the two tabs opened from the Tampermonkey menu (Open the filer tabs), pin both and keep them open. Pause, dry run, leave dates and the sender list are on the WRE Dashboard (Inbox filer panel), with links to open the filer tabs. Builder cancellations get flagged too. Works across Ambrose, NthStar, Responsive, Reconstruct, Bentino and ARC (ARC tasks are named by the full PO like Lisa does). If a PO looks new but one open task already sits at that address without the PO number (unit style addresses like 42A - 42B/ count), the PO goes under that task's description with the PDF attached and the check item says so; two or more open there and it flags it instead. Quote tasks are never matched, and two open tasks for one ref is fine when only one already carries the PO number. Stops itself after 80 reads in a day. Task names stay inside AroFlo's 50 character limit (state and postcode dropped the way Lisa does it). The Outlook tab reloads itself if it goes quiet for 10 min, and the log on the dashboard shows what each tab is up to. A short pause (say to install a version) carries on where it left off, only a long one skips the backlog. A second filer tab never picks up a job another tab is mid way through. Uploads follow AroFlo's own upload box state by state and only press Done on Complete; a failed one says where it got to, keeps the PDF, and Try again on the check item redoes just the upload. If one filer tab goes quiet for 8 min (closed, moved, or dropped by Chrome), the other opens it again. Uploads go through the task's own Add button on the Documents & Photos tab (the page's top menu Add puts files in company documents). Proven live 19/10: creating a task and location, the header save after appending a PO. Still to prove: the PDF upload landing on the task.
- WRE Clipboard Brain 1.1 (AutoHotkey v2, not Tampermonkey): download wre-clipboard-brain.ahk and double click it. Select text, then Ctrl+Alt+1 PO lines for the boys, Ctrl+Alt+2 customer text in your style, Ctrl+Alt+3 promise check, Ctrl+Alt+4 tidy an invoice description into your usual invoice style. Preview before anything pastes.
- Desk Panel 2.6 (PC server for the iPad desk panel, not Tampermonkey): download the panel folder, setup steps in panel/README.txt. Dark tiles with an icon each, a Favourites tab, a Lads tab and an at-a-glance bar showing what notes, photos and timesheets are still owed (from the WRE Calendar NPT issues in Todoist, token saved on the PC only), where you can OK an item or tick an issue off like on the dashboard, an Ambrose tab and glance line for photos and reports still to go up on Ambrose (the calendar's A letters), open work sites, run the WRE checks through the dashboard (inbox check lets you pick the day and pulls it first), run AHK files, fire the Clipboard Brain hotkeys and lock the PC. Change any tile's icon from the iPad (pencil button) or drop images in the icons folder on the PC. Home wifi only. Updates itself from this repo every 15 minutes (panel, buttons and Clipboard Brain), so button changes go in panel/buttons.json here.

Saved settings (API key, signature, Todoist token) live in each device's Tampermonkey, never in this repo.
