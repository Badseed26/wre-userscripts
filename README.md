# wre-userscripts

Tampermonkey scripts for WRE. Open an install link in a browser with Tampermonkey and hit Install. Updates come through automatically.

- Ambrose <-> AroFlo jump (jump buttons, PO chips, invoice log, auto-reload): https://raw.githubusercontent.com/Badseed26/wre-userscripts/main/ambrose-aroflo-jump.user.js
- AroFlo photo grab (Ambrose): https://raw.githubusercontent.com/Badseed26/wre-userscripts/main/aroflo-photo-grab.user.js
- AroFlo to Ambrose photo drag (PC only): https://raw.githubusercontent.com/Badseed26/wre-userscripts/main/aroflo-photo-drag.user.js
- Tradies Web quick fill (Ambrose): https://raw.githubusercontent.com/Badseed26/wre-userscripts/main/tradies-quick-fill.user.js
- WRE Calendar NPT: https://raw.githubusercontent.com/Badseed26/wre-userscripts/main/wre-calendar-npt.user.js

Saved settings (API key, signature, Todoist token) live in each device's Tampermonkey, never in this repo.
